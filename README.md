# Sample Spring Boot

A simple Spring Boot project demonstrating the basic structure and development of RESTful web applications using Spring Boot.

## 🚀 Features

- Spring Boot 3.x
- Java 17
- Maven Build
- REST API
- Embedded Tomcat Server
- Easy project structure
- Ready for further development

## 🛠️ Technologies Used

| Technology | Version |
|------------|---------|
| Java | 17 |
| Spring Boot | 3.x |
| Maven | 3.x |
| Spring Web | Latest |
| IDE | Eclipse / IntelliJ IDEA |

## 📁 Project Structure

```
sample-springboot
│── src
│   ├── main
│   │   ├── java
│   │   ├── resources
│   │       ├── application.properties
│   ├── test
│── pom.xml
│── README.md
```

## 📦 Clone Repository

```bash
git clone https://github.com/lovachittumuri/sample-springboot.git
```

## ▶️ Run the Project

Navigate to the project folder:

```bash
cd sample-springboot
```

Run using Maven:

```bash
mvn spring-boot:run
```

Or run directly from your IDE as a Spring Boot application.

## 🔨 Build Project

```bash
mvn clean install
```

## 🌐 Default URL

```
http://localhost:8080
```

## 📖 API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | `/` | Sample Home Endpoint |

> Add additional REST endpoints here as your project grows.

## ⚙️ Configuration

Application configuration is located in:

```
src/main/resources/application.properties
```

Example:

```properties
server.port=8080
```

## 🧪 Running Tests

```bash
mvn test
```
